<h1 align="center">Create: Power Grid - Wires Expanded</h1>
Create: Power Grid - Wires Expanded is an addon for the Create: Power Grid mod featuring thicker wires and other components enabling bigger and better power networks.

Originally, this was started because I needed wires with lower resistance for my solar-setup.


## License

The Project uses multiple assets from the original Create: Power Grid mod;

- Copper Wire Texture
- Copper Wire Icon
- Insulated Wire Texture
- Insulated Wire Icon
- Iron Wire Texture
- Iron Wire Icon

The Icons were modified to include an indicator for the thickness, additionally, the copper wire icon is used in the Mod's logo.
